# ToDo List

A simple, responsive to-do list built HTML and Javascript to practice Bootstrap.

 Add tasks, edit them, mark them as completed, delete them, and filter the list by status. Tasks are saved in the browser and remain available after refreshing the page.

## Features

* Add tasks using the Add button or the Enter key.
* Edit tasks directly in the list.
* Complete tasks by clicking the check button.
* Reactivate tasks by clicking the check button again.
* Delete tasks from the list.
* Filter tasks to display all, active, or completed tasks.
* Persistent storage using localStorage to keep tasks after refreshing the page.
* Responsive layout using Bootstrap’s grid system and utility classes.
